# Owner-controlled development

This repository is publicly readable, but does not solicit community maintenance.
Only explicitly authorized collaborators may contribute through the repository's
enabled contribution flow. The owner grants all write access; forks do not grant
permission to push or merge into this repository.

Issues and Discussions are disabled. Pull requests are restricted to collaborators
where supported, otherwise disabled. The actual applied settings and exceptions are
recorded in [publication record](docs/REPOSITORY-PUBLICATION-RECORD.md).
The canonical backlog is [AUCDEV-BACKLOG](docs/chatgpt-project/AUCDEV-BACKLOG.md).

Authorized development uses bounded scope, exact SHAs, deterministic checks, and a
previously qualified independent auditor. Keep runtime changes separate from
repository governance. Never commit credentials, private run archives, customer
data, or local auth/session files. No maintainer role or response-time promise is implied.
