## 4. Corrected static gate contract — GAP-D-STATIC-V2 (PROPOSED DESIGN; replaces the defective census wording of the prior record's Section 7.2 condition 2)

### 4.1 Census scope

The census parses each of the eight pinned production-module sources with a data-only `ast.parse` (the modules are NEVER imported or executed by the census) and enumerates every AST region that EXECUTES at import time: every module-body statement including all expressions nested within them (including comprehensions, which execute inline), every class-body statement (class bodies execute at class creation), every function/class decorator expression, and every default-argument and annotation expression; the BODIES of function and lambda definitions are excluded (they execute only when called). This is the semantically correct import-time scope; the prior "zero top-level calls" observation evidently counted only bare top-level expression statements and therefore missed calls nested in assignment values, for-iterables and decorators — the root cause of the false claim (Section 2).

### 4.2 Module-level statement grammar (default-deny)
